# Scoring governance

Scoring governance now lives in the canonical guide:

**[Scoring and controls → Scoring governance](scoring-and-controls.md#scoring-governance-how-rules-change)**

Summary: propose rule/control changes with provenance, tests, browser
regeneration, validation corpus updates when score meaning changes, and a
CHANGELOG entry. Never fold smells or length into the published score without
new evidence.

Community false-positive / false-negative reports use the issue templates under
`.github/ISSUE_TEMPLATE/`.
